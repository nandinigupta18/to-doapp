# TaskFlow — Modern To-Do Application

A modern, fast, and responsive Task Management web application built with pure **HTML5**, **Vanilla CSS**, and **Vanilla JavaScript**. Zero build steps or external dependencies required.

---

## ✨ Features

- **⚡ Add Task with Rich Metadata**:
  - Task title with validation and smooth error shake.
  - Priority levels with distinct indicators: High (🔥), Medium (⚡), and Low (🌱).
  - Categorization: Work (💼), Personal (👤), Study (📚), Health (🧘), and Finance (💳).
  - Optional Due Date picker with automated overdue indicators.
- **✨ Micro-Interactions & Aesthetics**:
  - Modern glassmorphism dark & light theme with smooth switching.
  - Ambient glowing gradient backdrop orbs.
  - Animated checkboxes with custom SVG checkmarks.
  - Pin & Star important tasks to keep them prominent.
  - Slide-in and slide-out micro-animations for adding and deleting tasks.
- **📊 Real-time Progress & Daily Velocity**:
  - Dynamic progress bar and completion percentage tracker.
  - Contextual motivational greetings based on completion velocity.
  - Celebratory **Particle Confetti Burst** when finishing tasks!
- **🔍 Filter & Search**:
  - Instant live search bar with quick clear.
  - Filter tabs: **All**, **Active**, **Done**, and **Starred**.
  - Sort by: *Newest first*, *Oldest first*, *Priority (High to Low)*, or *Due Date*.
- **✏️ Task Editing**:
  - In-app modal dialog to edit title, priority, category, or due date.
- **💾 Local Persistence**:
  - Automatically saves all tasks and theme settings to `localStorage`.
- **⌨️ Keyboard Shortcuts**:
  - <kbd>Enter</kbd> inside task input to immediately add task.
  - <kbd>/</kbd> to quickly jump focus to search.
  - <kbd>Esc</kbd> to clear search or close edit modal.
